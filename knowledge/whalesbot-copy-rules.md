# WhalesBot 文案规范（速查）

最后更新：2026-11-27。完整规则以 SOUL.md 文案红线为准，这里是干活时的速查版。

1. 写之前先去官网 https://www.whalesbot.ai/ 核实产品名和功能，不凭印象写。
2. 禁用词：mind control / Mindcontrol。替代：brainwaves、focus、brain-computer interface (BCI)、hands-free control。
3. Mentix：产品名在 YouTube 文案里写作 WhalesBot Mentix；头环本身有按键，不许说无按键；演示亮点是「不用手持控制器」。
4. 英文文案：写观众能看到的画面，先勾好奇心，短句讲动作，结尾轻收；面向青少年，好玩一眼懂。
5. 标题分两种：
   - Shorts：可以 punchy、带梗。
   - 普通 Video：不用 Shorts 风格；要短，带产品名+功能+品类词（BCI、STEM/AI 教育等）；不要把卖点在标题里说尽，不要只写「控制机器人」（Mentix 还能控制无人机等，标题里不枚举）。
6. 描述里的链接用裸 URL（https://www.whalesbot.ai/），不用 markdown 链接。
7. 官方号口吻：不个人化、不平铺直叙，标题和描述都要有 hook。
8. 拍摄/剪辑：先找值得拍的动作，再定开场、运镜、转场、节奏；幽默靠动作和运镜，不硬演。
